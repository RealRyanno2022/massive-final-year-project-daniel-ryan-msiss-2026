Project background and Requirement
Project overview from client: Extract and quantify ESG-related content from SEC 10-K
filings using NLP techniques (keyword analysis, embeddings) to create time-series ESG
scores for S&P 500 companies from 2015-2024. Track how corporate ESG discourse
evolved during the ESG investing boom and recent backlash by comparing your extracted
signals against Google Trends data for ESG-related searches. Analyze whether periods of
high public ESG interest correlate with performance differences between high-ESG and
low-ESG companies. This project combines practical NLP skills, financial data analysis,
and behavioral finance insights while working with real-world datasets including
Massive.io’s market data and SEC filings
